FLÁVIA GODOI — LANDING PAGE
Abra index.html no navegador ou use Live Server. HTML, CSS e JavaScript independentes, sem build.
Configure WHATSAPP no início de script.js com o número oficial (55 + DDD + número). Até lá os botões abrem o Instagram oficial informado.
As imagens são recortes das capturas enviadas e a marca fornecida. Antes de publicar, substitua por fotos originais em alta resolução, confirme autorização de uso de imagens de pacientes e adequação às normas profissionais, e valide textos, procedimentos, registro e locais com a profissional. As fotos dos cards são ilustrativas do portfólio, não confirmação do procedimento específico retratado. Não há depoimentos inventados.
Para publicar: envie todos os arquivos e a pasta assets para Cloudflare Pages, Vercel ou outro host estático. As fontes externas são opcionais; há fontes de fallback.
