ESSÊNCIA ESTÉTICA — LANDING PAGE
Abra index.html no navegador ou use Live Server. HTML, CSS e JavaScript independentes, sem build.
O site utiliza uma marca genérica, sem nome de profissional, registro, endereço ou rede social pessoal.
WHATSAPP fica vazio no início de script.js. Sem um número válido, os botões levam à seção de contato, que informa que os agendamentos serão divulgados em breve. Para habilitar o WhatsApp de uma clínica, configure o número oficial (55 + DDD + número) e atualize as informações de agendamento e local em index.html.
As fotos em assets/estetica são ilustrativas do Pexels; as fontes estão listadas abaixo. Elas não representam equipe, pacientes ou resultados da clínica. Os cards de procedimentos mantêm imagens ilustrativas genéricas. Não há depoimentos ou resultados atribuídos à clínica.
Para publicar: envie todos os arquivos e a pasta assets para Cloudflare Pages, Vercel ou outro host estático. As fontes externas são opcionais; há fontes de fallback.
